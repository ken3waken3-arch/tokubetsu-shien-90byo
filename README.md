# 学びに参加できる環境をつくる｜特別支援教育 90秒解説

文部科学省の審議まとめをもとに、特別支援教育の事実・審議段階の提案・授業への提案を分けて掲載するスマートフォン対応サイトです。

## 内容

- `index.html`：90秒スライド再生、要点検索、出典、配布資料へのリンク
- `assets/scene-01.svg`〜`scene-06.svg`：解説用の図版
- `90秒解説台本.txt`、`字幕.srt`、`字幕.vtt`：ナレーション原稿と字幕
- `配布資料.pdf`：A4一枚の要点整理
- [Canva編集デザイン](https://canva.link/tf6y303ntb19esk)：6枚のスライド
- `公開手順.md`：GitHub Pages公開情報

## 再生形式

サイト上では音声なしの約90秒スライド解説を再生できます。MP4動画ではありません。Canvaの編集デザインから音声や映像を追加して書き出せます。

## 根拠資料

文部科学省「次期学習指導要領等に向けた審議まとめ」（2026年10月5日）、資料1/4「特別支援教育」印刷頁114–123、資料2/4 印刷頁510–512、資料4/4 印刷頁993–994。審議段階の改善方向を扱い、確定した学習指導要領とは区別しています。
